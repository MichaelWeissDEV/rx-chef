## J. Compact UI, output workspace and release preparation

The shared GUI now uses one workspace bar and collapsed graph/recipe tool
sections. Operations and inspector/input panels can be hidden; named outputs
support tabs, side-by-side comparison, hiding/restoration, collapse and movable,
resizable floating panels inside the same page. Recipe results can retain up to
six snapshots / 16 MiB in memory for comparison; they never enter project files.
Auto-Bake is opt-in, debounced by 500 ms, runs each semantic/input revision once,
and waits for an existing worker. Layout/display changes do not submit jobs.
Graph edge routing offers rounded, square and flowing styles; Auto-align keeps
new nodes in dependency layers. Automatic fit is bounded to avoid oversized cards.

Transformation steps explain operations, defaults, bindings, embedded recipe
order and current node status/timings/output byte sizes. The standalone SVG
contains the whole graph and step list. It escapes text, uses no external
resources, omits payloads and redacts sensitive/unknown argument values. Ordinary
literals still require review. Fields over 1000 characters are shortened in the
image. Graph metadata is not an intermediate-payload trace.

Focused evidence: 107 Web unit tests/typecheck/lint PASS, complete 32-test browser
suite PASS, and four focused panel/Auto-Bake/report browser tests repeated after
visual corrections. Visual review found a zero-width canvas when both sidebars

nodes and usable canvas width. Narrow-menu overflow and file-menu pointer
