New tests cover pre-dispatch/submit/active cancellation, repeated requests, connection
replacement, stale success and remote-cancel failure. A requested cancellation is
not reported as terminated until terminal status arrives. An unsupervised custom
client cannot physically cancel a direct in-process call; its result is discarded.

Projects with three graphs, two recipes, metadata history/settings survive export
and reload with explicitly rebound data. IndexedDB tests cover concurrent tabs,
committed deletion, abort after put success and injected quota failure. The quota
test injects QuotaExceededError; it does not claim to exhaust the browser disk.
Browser IndexedDB, native webview storage and CLI/store directories are separate
local databases; portable export/import shares validation, not synchronization.
