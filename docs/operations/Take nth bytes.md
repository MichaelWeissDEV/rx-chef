# Take nth bytes

Takes every nth byte starting with a given byte.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Take nth bytes"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Take every | `4` | Take every nth byte |
| 2 | Starting at | `0` | Starting byte offset |
| 3 | Apply to each line | `false` | If true, apply to each line separately |
