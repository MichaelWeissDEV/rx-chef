# From Octal

Converts an octal byte string back into its raw value. e.g. '110 145 154 154 157' becomes 'Hello'.

- Input: `String`
- Output: `Bytes`
- CLI: `rxchef run "From Octal"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Space` | Delimiter between octal values (Space, Comma, Semi-colon, Colon, Line feed, CRLF) |
