# From Morse Code

Translates Morse Code into (upper case) alphanumeric characters.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "From Morse Code"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Letter delimiter | `Space` | The delimiter between letters |
| 2 | Word delimiter | `Line feed` | The delimiter between words |
