# Hex to PEM

Converts a hexadecimal DER (Distinguished Encoding Rules) string into PEM (Privacy Enhanced Mail) format.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Hex to PEM"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Header string | `CERTIFICATE` | PEM header/footer label (e.g. CERTIFICATE, RSA PRIVATE KEY) |
