# Series chart

A time series graph is a line graph of repeated measurements taken over regular time intervals.

- Input: `String`
- Output: `HTML`
- CLI: `rxchef run "Series chart"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Record delimiter | `\\n` | Character(s) that separate records |
| 2 | Field delimiter | `,` | Character(s) that separate fields |
| 3 | X label | `<empty>` | Label for the X axis |
| 4 | Point radius | `1` | Radius of points in the graph |
| 5 | Series colours | `mediumseagreen, dodgerblue, tomato` | Comma-separated list of colours for each series |
