# Render Image

Displays the input as an image. Supports the following formats: jpg/jpeg, png, gif, webp, bmp, ico.

- Input: `Bytes`
- Output: `HTML`
- CLI: `rxchef run "Render Image"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Input format | `Raw` | Raw, Base64, or Hex |
