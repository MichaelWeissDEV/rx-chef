# CMAC

CMAC is a block-cipher based message authentication code algorithm. AES-CMAC uses AES encryption with a 128, 192, or 256-bit key.

- Input: `Binary`
- Output: `String`
- CLI: `rxchef run "CMAC"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Key | `<empty>` | Encryption key (Hex, UTF8, Latin1, or Base64) |
| 2 | Encryption algorithm | `AES` | Encryption algorithm (AES) |
