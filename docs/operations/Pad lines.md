# Pad lines

Add the specified number of the specified character to the beginning or end of each line.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Pad lines"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Position | `Start` | Where to add padding: Start or End |
| 2 | Length | `5` | Number of padding characters to add |
| 3 | Character | ` ` | Character to use for padding |
