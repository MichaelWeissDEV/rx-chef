# To Octal

Converts the input string to octal bytes separated by the specified delimiter. e.g. 'Hello' becomes '110 145 154 154 157'.

- Input: `Bytes`
- Output: `String`
- CLI: `rxchef run "To Octal"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Space` | Delimiter between octal values (Space, Comma, Semi-colon, Colon, Line feed, CRLF) |
