# CSS Minify

Compresses Cascading Style Sheets (CSS) code by removing unnecessary whitespace and optionally stripping block comments.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "CSS Minify"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Preserve comments | `false` | Keep CSS block comments in output |
