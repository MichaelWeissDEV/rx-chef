# From Binary

Converts a binary string back into its raw form. e.g. '01001000 01101001' becomes 'Hi'

- Input: `String`
- Output: `Bytes`
- CLI: `rxchef run "From Binary"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Space` | The delimiter between binary groups (Space, Comma, Semi-colon, Colon, Line feed, CRLF, None) |
| 2 | Byte Length | `8` | Number of bits per byte (default 8) |
