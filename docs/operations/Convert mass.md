# Convert mass

Converts a unit of mass to another format.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Convert mass"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Input units | `Kilograms (kg)` | Input mass unit |
| 2 | Output units | `Grams (g)` | Output mass unit |
