# Set Difference

Calculates the difference, or relative complement, of two sets.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Set Difference"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Sample delimiter | `\\n\\n` | Delimiter separating the two input sets |
| 2 | Item delimiter | `,` | Delimiter separating items within each set |
