# Generate Image

Generates an image using the input as pixel values.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Generate Image"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Mode | `Greyscale` | Pixel representation mode |
| 2 | Pixel Scale Factor | `8` | Scale factor for pixels |
| 3 | Pixels per row | `64` | Width of the image in pixels |
