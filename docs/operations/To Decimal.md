# To Decimal

Converts the input data to an ordinal integer array. e.g. 'Hello' becomes '72 101 108 108 111'.

- Input: `Bytes`
- Output: `String`
- CLI: `rxchef run "To Decimal"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Space` | The delimiter between decimal values |
| 2 | Support signed values | `false` | Whether to treat bytes as signed (-128 to 127) |
