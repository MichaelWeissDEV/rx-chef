# JavaScript Beautify

Parses and pretty prints valid JavaScript code. Note: This implementation uses heuristic-based formatting as a full JS parser is not available.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "JavaScript Beautify"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Indent string | `    ` | String to use for each level of indentation |
