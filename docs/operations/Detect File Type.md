# Detect File Type

Attempts to guess the MIME (Multipurpose Internet Mail Extensions) type of the data based on 'magic bytes'.

- Input: `Bytes`
- Output: `String`
- CLI: `rxchef run "Detect File Type"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Images | `true` | Detect image files |
| 2 | Video | `true` | Detect video files |
| 3 | Audio | `true` | Detect audio files |
| 4 | Documents | `true` | Detect document files |
| 5 | Applications | `true` | Detect application files |
| 6 | Archives | `true` | Detect archive files |
