# SQL Beautify

Indents and prettifies Structured Query Language (SQL) code.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "SQL Beautify"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Indent string | `\\t` | String used for indentation (e.g. tab or spaces) |
