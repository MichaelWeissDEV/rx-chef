# Generate all hashes

Generates all available hashes and checksums for the input.

- Input: `Bytes`
- Output: `String`
- CLI: `rxchef run "Generate all hashes"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Length (bits) | `All` | Filter hashes by output length |
| 2 | Include names | `true` | Include the name of the hash in the output |
