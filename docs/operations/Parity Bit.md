# Parity Bit

A parity bit, or check bit, is the simplest form of error detection. It is a bit which is added to a string of bits and represents if the number of 1's in the binary string is an even number or odd number.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Parity Bit"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Mode | `Even Parity` | Even or Odd parity |
| 2 | Position | `Start` | Start or End |
| 3 | Encode or Decode | `Encode` | Encode or Decode |
| 4 | Delimiter | `<empty>` | Delimiter for blocks |
