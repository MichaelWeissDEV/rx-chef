# To Charcode

Converts text to its unicode character code equivalent.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "To Charcode"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Space` | The character code delimiter |
| 2 | Base | `16` | The numerical base of the codes (2-36) |
