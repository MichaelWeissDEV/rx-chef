# ECDSA Signature Conversion

Convert an ECDSA signature between hex, asn1 and json.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "ECDSA Signature Conversion"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Input Format | `Auto` | The format of the input signature |
| 2 | Output Format | `ASN.1 HEX` | The desired output format |
