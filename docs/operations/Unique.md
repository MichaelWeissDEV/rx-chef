# Unique

Removes duplicate strings from the input.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Unique"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Line feed` | Line feed, CRLF, Space, Comma, etc. |
| 2 | Display count | `false` | Prefix each unique item with its occurrence count |
