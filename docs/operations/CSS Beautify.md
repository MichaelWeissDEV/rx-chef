# CSS Beautify

Indents and prettifies Cascading Style Sheets (CSS) code.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "CSS Beautify"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Indent string | `    ` | String to use for each level of indentation |
