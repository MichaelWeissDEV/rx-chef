# XOR

XOR the input with the given key.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "XOR"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Key | `<empty>` | Key to XOR with input |
| 2 | Scheme | `Standard` | Scheme (Standard, Input differential, Output differential, Cascade) |
| 3 | Null preserving | `false` | If true, preserve null bytes |
