# Unzip

Decompresses data using the PKZIP algorithm and displays it per file, with support for passwords.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Unzip"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Password | `<empty>` | Password for encrypted zip files |
| 2 | Verify result | `false` | Verify result (ignored in this port) |
