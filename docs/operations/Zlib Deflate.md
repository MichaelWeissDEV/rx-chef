# Zlib Deflate

Compresses data using the deflate algorithm with zlib headers (RFC 1950).

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Zlib Deflate"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Compression type | `Dynamic` | Compression level: Dynamic (default), Best speed, Best compression, No compression |
