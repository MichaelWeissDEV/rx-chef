# Generate RSA Key Pair

Generate an RSA key pair with a given number of bits.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Generate RSA Key Pair"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | RSA Key Length | `2048` | RSA Key Length |
| 2 | Output Format | `PEM` | Output Format |
