# Image Brightness / Contrast

Adjust the brightness or contrast of an image.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Image Brightness / Contrast"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Brightness | `0` | The amount to adjust the brightness by. (-100 to 100) |
| 2 | Contrast | `0` | The amount to adjust the contrast by. (-100 to 100) |
