# Split

Splits a string into sections around a given delimiter.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Split"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Split delimiter | `Comma` | Delimiter to split on (e.g. Comma, Line feed, or literal string) |
| 2 | Join delimiter | `Line feed` | Delimiter to rejoin with (e.g. Line feed, CRLF) |
