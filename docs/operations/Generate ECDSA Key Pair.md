# Generate ECDSA Key Pair

Generate an ECDSA key pair with a given Curve.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Generate ECDSA Key Pair"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Elliptic Curve | `P-256` | Curve to use |
| 2 | Output Format | `PEM` | Format of the output keys |
