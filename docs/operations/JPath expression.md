# JPath expression

Extract information from a JSON object with a JPath query.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "JPath expression"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Query | `<empty>` | The JPath query to run |
| 2 | Result delimiter | `\\n` | The delimiter to use between results |
