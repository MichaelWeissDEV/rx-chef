# Unicode Text Format

Adds Unicode combining characters to change formatting of plaintext.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Unicode Text Format"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Underline | `false` | Underline |
| 2 | Strikethrough | `false` | Strikethrough |
