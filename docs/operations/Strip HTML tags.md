# Strip HTML tags

Removes all HTML tags from the input. Optionally removes indentation and excess line breaks.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Strip HTML tags"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Remove indentation | `true` | Remove leading whitespace from lines |
| 2 | Remove excess line breaks | `true` | Collapse multiple blank lines |
