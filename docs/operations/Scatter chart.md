# Scatter chart

Plots two-variable data as single points on a graph.

- Input: `String`
- Output: `HTML`
- CLI: `rxchef run "Scatter chart"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Record delimiter | `Line feed` | The record delimiter |
| 2 | Field delimiter | `Comma` | The field delimiter |
| 3 | Use column headers as labels | `true` | Use column headers as labels |
| 4 | X label | `<empty>` | X label |
| 5 | Y label | `<empty>` | Y label |
| 6 | Colour | `blue` | The colour of the points |
| 7 | Point radius | `5` | The radius of the points |
| 8 | Use colour from third column | `false` | Use colour from third column |
