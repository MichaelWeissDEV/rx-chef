# Raw Deflate

Compresses data using the raw deflate algorithm without any headers (RFC 1951).

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Raw Deflate"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Compression type | `Dynamic` | Compression level: Dynamic (default), Best speed, Best compression, No compression |
