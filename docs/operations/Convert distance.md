# Convert distance

Converts a unit of distance to another format.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Convert distance"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Input units | `Metres (m)` | Input distance unit |
| 2 | Output units | `Kilometres (km)` | Output distance unit |
