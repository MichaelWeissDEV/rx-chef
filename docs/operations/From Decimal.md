# From Decimal

Converts the data from an ordinal integer array back into its raw form.

- Input: `String`
- Output: `Bytes`
- CLI: `rxchef run "From Decimal"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Space` | The character code delimiter |
| 2 | Support signed values | `false` | Support negative values (signed 8-bit integers) |
