# Frequency distribution

Displays the distribution of bytes in the data as a frequency table.

- Input: `Bytes`
- Output: `String`
- CLI: `rxchef run "Frequency distribution"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Show 0%s | `true` | Include bytes that do not appear in the input |
| 2 | Show ASCII | `true` | Include ASCII character column |
