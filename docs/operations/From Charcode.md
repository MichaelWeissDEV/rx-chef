# From Charcode

Converts unicode character codes back into text.

- Input: `String`
- Output: `Bytes`
- CLI: `rxchef run "From Charcode"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Space` | The character code delimiter |
| 2 | Base | `16` | The numerical base of the codes |
