# Extract MAC addresses

Extracts all Media Access Control (MAC) addresses from the input.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Extract MAC addresses"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Display total | `false` | Display total found |
| 2 | Sort | `false` | Sort results |
| 3 | Unique | `false` | Remove duplicate results |
