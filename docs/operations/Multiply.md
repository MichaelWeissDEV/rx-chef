# Multiply

Multiplies a list of numbers. If an item in the string is not a number it is excluded from the list. e.g. 0x0a 8 .5 becomes 40

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Multiply"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Line feed` | Character that separates numbers in the input |
