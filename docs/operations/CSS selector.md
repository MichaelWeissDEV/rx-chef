# CSS selector

Extract information from an HTML document with a CSS selector

- Input: `String`
- Output: `String`
- CLI: `rxchef run "CSS selector"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | CSS selector | `<empty>` | The CSS selector query. |
| 2 | Delimiter | `\\n` | The character(s) to delimit the output. |
