# XPath expression

Extract information from an XML document with an XPath query

- Input: `String`
- Output: `String`
- CLI: `rxchef run "XPath expression"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | XPath | `<empty>` | The XPath query |
| 2 | Result delimiter | `\\n` | The delimiter to use between results |
