# Bit shift right

Shifts the bits in each byte towards the right by the specified amount.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Bit shift right"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Amount | `1` | Amount to shift right |
| 2 | Type | `Logical shift` | Shift type (Logical or Arithmetic) |
