# Generate Lorem Ipsum

Generate varying length lorem ipsum placeholder text. Length type: Paragraphs, Sentences, Words, Bytes.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Generate Lorem Ipsum"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Length | `3` | Number of units to generate |
| 2 | Length in | `Paragraphs` | Unit type: Paragraphs, Sentences, Words, Bytes |
