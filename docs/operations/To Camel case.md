# To Camel case

Converts the input string to camel case.

Camel case is all lower case except letters after word boundaries which are uppercase.

e.g. thisIsCamelCase

- Input: `String`
- Output: `String`
- CLI: `rxchef run "To Camel case"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Attempt to be context aware | `false` | Attempt to nicely transform variable and function names. |
