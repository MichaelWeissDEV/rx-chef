# Resize Image

Resizes an image to the specified width and height values.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Resize Image"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Width | `100` | Width of the new image |
| 2 | Height | `100` | Height of the new image |
| 3 | Unit type | `Pixels` | Pixels or Percent |
| 4 | Maintain aspect ratio | `false` | Whether to maintain the aspect ratio |
| 5 | Resizing algorithm | `Bilinear` | The algorithm to use for resizing |
