# To HTML Entity

Converts characters to HTML entities<br><br>e.g. <code>&amp;</code> becomes <code>&amp;<span>amp;</span></code>

- Input: `String`
- Output: `String`
- CLI: `rxchef run "To HTML Entity"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Convert all characters | `false` | Convert all characters to HTML entities |
| 2 | Convert to | `Named entities` | The type of HTML entity to convert to |
