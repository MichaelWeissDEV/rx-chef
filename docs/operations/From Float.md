# From Float

Convert from IEEE754 Floating Point Numbers to raw bytes.

- Input: `String`
- Output: `Bytes`
- CLI: `rxchef run "From Float"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Endianness | `Big Endian` | Big Endian or Little Endian |
| 2 | Size | `Float (4 bytes)` | Float (4 bytes) or Double (8 bytes) |
| 3 | Delimiter | `Space` | Delimiter separating float values (Space, Comma, etc.) |
