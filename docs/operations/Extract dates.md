# Extract dates

Extracts dates in the following formats
yyyy-mm-dd
dd/mm/yyyy
mm/dd/yyyy
Dividers can be any of /, -, . or space

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Extract dates"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Display total | `false` | Display total found |
