# Change IP format

Convert an IP address from one format to another, e.g. 172.20.23.54 to ac141736

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Change IP format"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Input format | `Dotted Decimal` | Input format: Dotted Decimal, Decimal, Octal, Hex |
| 2 | Output format | `Dotted Decimal` | Output format: Dotted Decimal, Decimal, Octal, Hex |
