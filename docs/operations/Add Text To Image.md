# Add Text To Image

Adds text onto an image.<br><br>Text can be horizontally or vertically aligned, or the position can be manually specified.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Add Text To Image"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Text | `<empty>` | The text to add. |
| 2 | Horizontal align | `None` | None, Left, Center, Right |
| 3 | Vertical align | `None` | None, Top, Middle, Bottom |
| 4 | X position | `0` | Manual X position |
| 5 | Y position | `0` | Manual Y position |
| 6 | Size | `32` | Font size |
| 7 | Red | `255` | Red component (0-255) |
| 8 | Green | `255` | Green component (0-255) |
| 9 | Blue | `255` | Blue component (0-255) |
| 10 | Alpha | `255` | Alpha component (0-255) |
