# To Float

Convert to IEEE754 Floating Point Numbers.

- Input: `Bytes`
- Output: `String`
- CLI: `rxchef run "To Float"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Endianness | `Big Endian` | Big Endian or Little Endian |
| 2 | Size | `Float (4 bytes)` | Float (4 bytes) or Double (8 bytes) |
| 3 | Delimiter | `Space` | Delimiter to join float values (Space, Comma, etc.) |
