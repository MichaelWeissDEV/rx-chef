# Convert speed

Converts a unit of speed to another format.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Convert speed"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Input units | `Metres per second (m/s)` | Input speed unit |
| 2 | Output units | `Kilometres per hour (km/h)` | Output speed unit |
