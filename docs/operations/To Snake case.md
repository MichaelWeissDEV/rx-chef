# To Snake case

Converts the input string to snake case.

Snake case is all lower case with underscores as word boundaries.

e.g. this_is_snake_case

- Input: `String`
- Output: `String`
- CLI: `rxchef run "To Snake case"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Attempt to be context aware | `false` | Attempt to nicely transform variable and function names. |
