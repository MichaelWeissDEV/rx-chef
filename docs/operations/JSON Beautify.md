# JSON Beautify

Indents and pretty prints JavaScript Object Notation (JSON) code.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "JSON Beautify"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Indent string | `    ` | String used for indentation (e.g. tab or spaces) |
| 2 | Sort Object Keys | `false` | Sort keys in JSON objects alphabetically |
