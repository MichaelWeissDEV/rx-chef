# Compare CTPH hashes

Compares two Context Triggered Piecewise Hashing (CTPH) fuzzy hashes to determine the similarity between them on a scale of 0 to 100.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Compare CTPH hashes"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Line feed` | Delimiter between the two hashes (Line feed, CRLF, Space, Comma, Semi-colon) |
