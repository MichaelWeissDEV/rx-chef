# Jq

jq is a lightweight and flexible command-line JSON processor.

- Input: `JSON`
- Output: `String`
- CLI: `rxchef run "Jq"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Query | `.` | The jq query to run |
| 2 | Raw | `false` | If true, the output will be raw strings instead of JSON |
