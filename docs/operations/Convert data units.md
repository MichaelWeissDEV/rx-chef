# Convert data units

Converts a unit of data to another format (bits, bytes, kilobytes, etc.).

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Convert data units"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Input units | `Bytes (B)` | Input data unit |
| 2 | Output units | `Kilobytes (kB)` | Output data unit |
