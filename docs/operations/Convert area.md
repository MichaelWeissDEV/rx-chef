# Convert area

Converts a unit of area to another format.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Convert area"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Input units | `Square metre (sq m)` | Input area unit |
| 2 | Output units | `Square kilometre (sq km)` | Output area unit |
