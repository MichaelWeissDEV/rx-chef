# A1Z26 Cipher Decode

Converts alphabet order numbers into their corresponding alphabet character.<br><br>e.g. <code>1</code> becomes <code>a</code> and <code>2</code> becomes <code>b</code>.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "A1Z26 Cipher Decode"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Space` | Delimiter between numbers |
| 2 | Check format | `true` | Automatically detect delimiter from input format |
