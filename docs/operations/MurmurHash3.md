# MurmurHash3

Generates a MurmurHash v3 for a string input and an optional seed input

- Input: `String`
- Output: `Number`
- CLI: `rxchef run "MurmurHash3"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Seed | `0` | Positive integer only |
| 2 | Convert to Signed | `false` | Whether to convert the output to a signed 32-bit integer |
