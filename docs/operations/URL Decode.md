# URL Decode

Converts URI/URL percent-encoded characters back to their raw values. e.g. %3d becomes =

- Input: `String`
- Output: `String`
- CLI: `rxchef run "URL Decode"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Treat '+' as space | `true` | Convert '+' characters to spaces in addition to %20 |
