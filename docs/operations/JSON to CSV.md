# JSON to CSV

Converts JSON data to a CSV based on the definition in RFC 4180.

- Input: `JSON`
- Output: `String`
- CLI: `rxchef run "JSON to CSV"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Cell delimiter | `,` | The character(s) to use to separate cells |
| 2 | Row delimiter | `\\r\\n` | The character(s) to use to separate rows |
