# Extract Audio Metadata

Extract common audio metadata across MP3, WAV, FLAC, OGG, etc. Outputs normalized JSON.

- Input: `Binary`
- Output: `JSON`
- CLI: `rxchef run "Extract Audio Metadata"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Filename (optional) | `<empty>` | Filename |
| 2 | Max embedded text bytes | `524288` | Max text bytes |
