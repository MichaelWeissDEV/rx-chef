# Image Hue/Saturation/Lightness

Adjusts the hue / saturation / lightness (HSL) values of an image.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Image Hue/Saturation/Lightness"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Hue | `0` | The amount to adjust the hue by (degrees). |
| 2 | Saturation | `0` | The amount to adjust the saturation by (%). |
| 3 | Lightness | `0` | The amount to adjust the lightness by (%). |
