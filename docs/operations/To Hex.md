# To Hex

Converts the input string to hexadecimal bytes separated by the specified delimiter.

- Input: `Bytes`
- Output: `String`
- CLI: `rxchef run "To Hex"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `Space` | Delimiter between hex bytes (Space, Comma, Semi-colon, Colon, Line feed, CRLF, None, 0x with comma, \\x) |
| 2 | Bytes per line | `0` | Number of bytes per output line (0 = no wrapping) |
