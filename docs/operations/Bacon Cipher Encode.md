# Bacon Cipher Encode

Bacon's cipher or the Baconian cipher is a method of steganography devised by Francis Bacon in 1605. A message is concealed in the presentation of text, rather than its content.

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Bacon Cipher Encode"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Alphabet | `Standard (I=J and U=V)` | Alphabet variant (Standard or Complete) |
| 2 | Translation | `0/1` | Translation method (0/1 or A/B) |
| 3 | Keep extra characters | `false` | Keep non-alphabetic characters |
| 4 | Invert Translation | `false` | Invert 0/1 or A/B |
