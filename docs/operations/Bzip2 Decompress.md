# Bzip2 Decompress

Decompresses data using the Bzip2 algorithm.

- Input: `Bytes`
- Output: `Bytes`
- CLI: `rxchef run "Bzip2 Decompress"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Use low-memory, slower decompression algorithm | `false` | Use a slower algorithm that requires less memory |
