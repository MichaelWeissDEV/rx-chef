# HAS-160

HAS-160 is a cryptographic hash function designed for use with the Korean KCDSA digital signature algorithm.

- Input: `Bytes`
- Output: `String`
- CLI: `rxchef run "HAS-160"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Rounds | `80` | Number of rounds |
