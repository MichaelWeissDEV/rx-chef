# From Modhex

Converts a modhex byte string back into its raw value. Modhex is used in YubiKey.

- Input: `String`
- Output: `Bytes`
- CLI: `rxchef run "From Modhex"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Delimiter | `None` | Delimiter between modhex pairs (None, Space, Comma, Semi-colon, Colon, Line feed, CRLF) |
