# Extract hashes

Extracts potential hashes based on hash character length

- Input: `String`
- Output: `String`
- CLI: `rxchef run "Extract hashes"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Hash character length | `40` | The length of the hash in characters |
| 2 | All hashes | `false` | Extract all common hash lengths |
| 3 | Display Total | `false` | Display the total number of hashes found |
