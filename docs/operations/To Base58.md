# To Base58

Base58 is a notation for encoding arbitrary byte data, removing easily misread characters.

- Input: `Bytes`
- Output: `String`
- CLI: `rxchef run "To Base58"`

## Arguments

| # | Argument | Default | Description |
|---:|---|---|---|
| 1 | Alphabet | `123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz` | The Base58 alphabet |
