# rxchef-cli

The `rxchef` command-line interface for [rx-chef](https://rx-chef.readthedocs.io/),
a CyberChef-style toolkit of cryptographic, encoding, and data transformation
operations, ported to Rust.

```bash
cargo install rxchef-cli
printf 'hello' | rxchef run to_base64
```

See the [CLI documentation](https://rx-chef.readthedocs.io/en/latest/cli/reference/)
for the full command reference, and the
[project overview](https://rx-chef.readthedocs.io/) for the library, TUI,
and server interfaces.
